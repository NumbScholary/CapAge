# Experiment 0 full selection v1 launch

This marker launches the frozen 30-scenario selection benchmark for the two
preregistered candidates at medium effort, one trial per scenario, no tools,
and at most one infrastructure-only retry.

Judge-visible artifacts contain each frozen question and both verbatim model
outputs. Response numbers are local to each scenario and independently
randomized for each of two judges. The stable candidate mapping and both
presentation mappings remain in the restricted audit bundle until all human
scores are locked.

Opening this pull request authorizes the selection run only. It does not select
a model, expand CapAge authority, modify the frozen rubric or scenarios, or
authorize opening the restricted audit bundle before scoring is locked.
