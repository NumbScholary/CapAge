This file defines, but does not itself grant, the paid-run authorization for
the preregistered eighteen-cell synthetic comparison. The maximum aggregate
Anthropic API charge is 1,350 cents ($13.50), with a maximum of 75 cents per
cell.

Merging the gate does not run the experiment or authorize spending. A human
operator must separately provide the following exact phrase when manually
dispatching the workflow:

RUN_MATCHED_HOMEOSTASIS_V2_THREE_ARM_MAX_1350_CENTS

Authorization is limited to the frozen Control/V1/V2 synthetic sandbox cells.
It does not authorize real-world economic action, external contracts,
publication, recapitalization, extra cells, automatic provider retries, or any
expansion of CapAge's authority. Any ambiguous paid attempt stops for human
review instead of being replayed.
